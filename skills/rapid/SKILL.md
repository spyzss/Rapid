# 快科研 Rapid

根据用户要的交付物和当前材料，选择起点和终点。沿用已有稿件、结果、文献库、模板和项目的实验入口。把需要走的 playbook 列成短清单，已有合格产物的步骤直接接续。

| 步骤 | 何时打开 | 交接 |
|---|---|---|
| [1. 选题与定位](playbooks/01-frame.md) | 只有主题或想法，或稿件主张需要重定 | 问题、方法、核心主张 |
| [2. 查新与作者调研](playbooks/02-literature.md) | 需要找最近前作、补 related work 或查作者 | 前作差异、核实的引用 |
| [3. 资源与实验证据](playbooks/03-evidence.md) | 估资源、定最小实验、复用已有结果 | 资源预算和实验计划，或可引用的实测证据 |
| [4. 写稿与绘图](playbooks/04-draft.md) | 写论文、续稿或出图 | 源稿、引文、主图与源码 |
| [5. 审稿与返修](playbooks/05-review.md) | 模拟审稿、点选视角，或处理真实意见 | 意见、修订、待补证据 |
| [6. 投稿准备](playbooks/06-submit.md) | 要 PDF、投稿包、预印本或换 venue | 渲染稿和提交文件 |

## 选择 skill

用户点名时按用户选择。默认按每个 playbook 的条件选一条主路线，只有上游产物缺少某一项时才加载互补 skill。已有配置或结果能完成任务就复用。选中后，阅读 playbook 指向的固定版本上游 `SKILL.md` 和它在该分支需要的参考文件，按上游方法产出。在当前工作区按需读取，用户无需安装所有上游项目。遇到工具或后端缺失时，优先用当前环境的等价能力，再考虑表中备选。使用前确认会实际触发的操作在用户授权与预算内。

## 串起来

1. 选题交给查新。发现直接重合时，把最接近的前作和区别带回选题。差异明确后，把主张和最近 baseline 交给实验计划，估算数据、算力、时间和最小有效实验。
2. 写作和绘图共用核过的结果。引文核对可并行。只有 idea 或计划时交付可检验的主张、查新和实验计划，实测结果到手后接续。
3. 全流程用同版稿件审一轮，按意见回到最早受影响的步骤。贡献问题回到选题或查新，证据问题回到实验，表达问题回到写稿。更新相关稿件、表图与引文，再定点复审有实质变化的部分。按用户指定的终点交付。
