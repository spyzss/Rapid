# 1. 选题与定位

- **已有研究想法、结果或草稿**。用 `research-refine` 的 problem anchor、technical gap 和 method thesis，把已有材料收束成一个问题、一条方法主线和可检验的贡献。 [ARIS research-refine](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/9f30e834d24a337dbdd06fb20a1150d4376dfa59/skills/skills-codex/research-refine/SKILL.md)
- **只有宽方向**。用 `idea-discovery` 的构思分支，从领域问题和可复用资产收敛到少数候选。再把最有希望的候选交给查新。小试验进入第 3 步的预算与执行。 [ARIS idea-discovery](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/9f30e834d24a337dbdd06fb20a1150d4376dfa59/skills/skills-codex/idea-discovery/SKILL.md)

**交接**。研究问题、核心主张、候选方法和已有资产。给第 2 步指出最可能重合的工作或待查的机制。若已有目标 venue，提前读当届 track 的 scope 和材料要求，把会改变实验设计的要求带到第 3 步。
